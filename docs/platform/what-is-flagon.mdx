Flagon is a self-hostable **developer platform**. The core unit is a **Project**:
a deployable app, in the Vercel model, with no separate "app" layer. Everything
operates inside an **organization**, so URLs look like `app.flagon.io/<org>/...`,
with personal account settings at `/settings` as the one exception.

## Three principles

Flagon is built on three principles that shape everything in the product.

**API-first.** Every capability is an API operation first. The OpenAPI spec is
generated from the code, never hand-written, so if it isn't in the API, it
doesn't exist.

**AI-first.** Anything you can do in the UI you can do by asking the AI, and vice
versa. The assistant is wired in at the root, so every new capability becomes
available to it as it ships.

**AI, MCP, and API stay in lockstep.** The in-product agent, the MCP server at
`mcp.flagon.io`, and the HTTP API all expose the same operations from one shared
tool registry. Three front doors, one set of capabilities.

## The suite

The product suite is intentionally broad and grows over time: projects and
deployments today, with observability, a package registry, reporting and DORA
metrics, and repository insights over time.
