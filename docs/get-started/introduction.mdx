Flagon is a **developer platform** for building, shipping, and operating your
projects. Use it hosted at [app.flagon.io](https://app.flagon.io), or run the
whole thing yourself: it is open source and self-hostable end to end.

The core unit is a **project**: a deployable app. Every project lives inside an
**organization**, so your work, your team, and your access all sit in one place.

## Three ways to do everything

Anything you can do in Flagon, you can do three ways, backed by the same
permission-checked operations:

- **The dashboard.** A fast UI for creating and managing your organization,
  projects, members, and tokens.
- **The assistant.** Ask for what you want ("create a project called billing")
  and Flagon does it, or proposes it for you to confirm. The assistant is wired
  into the platform, so it grows as the product does.
- **The API and MCP.** Every capability is an HTTP API operation first, so you
  can script it, build on it, or point an external agent at
  [mcp.flagon.io](https://mcp.flagon.io).

## What you can do today

- Create and manage **organizations** and invite **members** with scoped roles.
- Create **projects** and organize your work inside an org.
- Mint **API tokens** with fine-grained **scopes** and drive the platform
  programmatically.
- Ask the **assistant** to do any of the above, and read these docs, on your
  behalf.

The suite grows from here: deployments, observability, a package registry, and
reporting are on the way, and each becomes available across the UI, the
assistant, and the API as it ships.
