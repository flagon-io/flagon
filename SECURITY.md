# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in Flagon, please report it
privately to **security@flagon.io** rather than opening a public issue or pull
request.

Include enough detail to reproduce the issue: the affected component or URL, the
steps to trigger it, and any proof of concept. We will acknowledge your report,
investigate, and keep you updated on progress and remediation.

We support responsible disclosure and will not pursue legal action against
good-faith research that respects our users' privacy and data and does not
degrade the service for others.

## Scope

This policy covers the code in this repository and the managed service at
[flagon.io](https://flagon.io). If you self-host Flagon, you are responsible for
the security of your own deployment.

See [flagon.io/security](https://flagon.io/security) for more on how Flagon
protects accounts and data.
