Everything the product does is an API call first. A documented HTTP API with token authentication and scopes, so anything you can do in the dashboard you can automate.

- OpenAPI-documented endpoints, always current with the product
- Token authentication with fine-grained scopes
- Consistent pagination and error shapes
- The same contract the dashboard itself is built on
