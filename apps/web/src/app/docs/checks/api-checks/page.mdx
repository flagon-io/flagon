# API checks

An **API check** sends a single HTTP request with full request setup and validates the
response with [assertions](/docs/checks/assertions). It is richer than the URL monitor:
send headers and a body, and assert on the status, response time, headers, the raw body,
or a JSON path. It is a **synthetic** check, billed per run.

## Configuration

- **URL** and **method** (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `HEAD`).
- **Headers** and a **request body** (for non-GET methods).
- **Follow redirects**.
- **[Assertions](/docs/checks/assertions)** against the response.
- **Degraded after** (default `5000ms`) and **failed after** (default `10000ms`, capped at
  30s).

## Example

```bash
curl -X POST https://api.flagon.io/v1/orgs/acme/checks \
  -H "Authorization: Bearer $FLAGON_TOKEN" -H "Content-Type: application/json" \
  -d '{
    "name": "Create order API",
    "type": "api",
    "config": {
      "url": "https://api.acme.com/orders",
      "method": "POST",
      "headers": { "authorization": "Bearer test-key" },
      "body": "{\"sku\":\"abc\"}",
      "assertions": [
        { "source": "status", "comparison": "equals", "target": "201" },
        { "source": "jsonBody", "property": "order.status", "comparison": "equals", "target": "created" }
      ]
    },
    "frequencySeconds": 300
  }'
```

For long, multi-step user flows in a real browser, use a
[browser check](/docs/checks/browser-checks) instead.
