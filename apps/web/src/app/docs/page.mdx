# Flagon documentation

Flagon is a self-hostable **developer platform**: one hub for your services,
projects, environments, and teams, with the products you'd otherwise buy or build
stitched into the same foundation. One organization, one login, one bill. These
docs cover the platform itself and each product built on it.

## Products

The **Catalog** is the centerpiece the platform is built around; **Feature Flags**
is available on it today, with more products shipping shortly.
