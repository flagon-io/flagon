# Feature flags on Flagon

Flagon feature flags let you change what your application does without shipping a
new build. You define a flag once in the console, decide who sees which value
with targeting rules, and read the result from your code through
[OpenFeature](https://openfeature.dev), the vendor-neutral flag standard.

Because evaluation speaks OpenFeature's remote protocol (OFREP), there is no
Flagon-specific client to learn or lock into: any OpenFeature SDK with an OFREP
provider works, in any language, and points at Flagon by URL.

## How it fits together

- **Flags and variants** are what you toggle. A boolean flag serves `true` or
  `false`; a multivariate flag serves one of several named values (a string,
  number, or JSON object).
- **Environments** keep Production, Preview, and Development separate. The same
  flag can be on in Development and off in Production.
- **Targeting rules and segments** decide which variant a given user or request
  receives, based on the context your app supplies.
- **SDK keys** authenticate evaluation. Each key is scoped to one environment,
  so a key can never read another environment's configuration.

## Two ways to evaluate

<CodeTabs
  tabs={[
    {
      label: "OpenFeature (recommended)",
      caption: "Node.js",
      code: `import { OpenFeature } from "@openfeature/server-sdk";
import { OFREPProvider } from "@openfeature/ofrep-provider";

await OpenFeature.setProviderAndWait(
  new OFREPProvider({
    baseUrl: "https://api.flagon.io",
    headers: [["Authorization", \`Bearer \${process.env.FLAGON_SDK_KEY}\`]],
  }),
);

const client = OpenFeature.getClient();
const showCheckout = await client.getBooleanValue("new-checkout", false, {
  targetingKey: "user-123",
});`,
    },
    {
      label: "REST (OFREP)",
      caption: "cURL",
      code: `curl -X POST "https://api.flagon.io/ofrep/v1/evaluate/flags/new-checkout" \\
  -H "Authorization: Bearer $FLAGON_SDK_KEY" \\
  -H "Content-Type: application/json" \\
  -d '{"context":{"targetingKey":"user-123"}}'`,
    },
  ]}
/>
