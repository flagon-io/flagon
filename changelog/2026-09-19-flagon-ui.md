Flagon UI (`@flagon-io/ui`) is our design system: an accessible, Radix-based
React component library, documented and published at
[ui.flagon.io](https://ui.flagon.io). It is the shared vocabulary the product is
built from, so the button you see in a login flow is the same button, with the
same behavior and the same accessibility guarantees, everywhere it appears.

We are shipping it as a first-class, long-term product, not an internal detail:

- Accessible by default, built on Radix primitives, keyboard and screen-reader
  ready out of the box.
- One place to change a component, so the app and everything downstream stay
  consistent.
- Documented on its own site, with every component and its usage in the open.

It is the foundation the rest of the platform's interface is built on, and it is
here to stay.
